# Props archive schema (`IKP1` v1) — Task 53 (D-T53-1)

Generated by `rust/tools/extract/extract-props.mjs` (per stage) and
`extract-special.mjs` (specials). Output: `<stage>.bin.gz` + `<stage>.json`
(+ `special.bin.gz` + `special.json`) in this directory. Deterministic:
re-running against the same upstream commit yields byte-identical files
(TR-3.4). All integers little-endian; all floats IEEE-754 f32.

## Binary layout (`*.bin.gz` = zlib gzip, level 9)

```
u32  magic            0x31504B49 ('IKP1' read as LE bytes)
u16  version          1
u16  bucketCount
  bucketCount × { u8 nameLen; nameLen bytes UTF-8 name; u8 nsFlag }
     name = JS material-bucket key without the '~ns' suffix (props.js L3129-3141);
     nsFlag 1 = the bucket never casts shadows (the '~ns' suffix).
     Decor-only bucket 'glass' = lamp glass (emissive shade, decor.js L304).
u32  templateCount
  templateCount × {
    u32 vertexCount; u32 indexCount;
    vertexCount × {
      i32 x, i32 y, i32 z        millimetres (i32 — pieredge/halyard local
                                  geometry exceeds the i16 mm range; D-T53-6⑥)
      i16 nx, i16 ny, i16 nz     ×1000, unit length
      u8  r, g, b                vertex colour (linear, = material colour ×
                                  geometry colour × AO falloff, mergeParts
                                  semantics props.js L1103; glow multipliers
                                  clamp to 255)
    }
    indexCount × u32             triangle list (winding already flipped for
                                  negative-determinant parts)
  }
  Templates are baked in PROP-LOCAL space (the placement begin matrix undone),
  welded on the quantisation grid and content-hash deduplicated; identical
  mirror twins share a template when their geometry matches.
u32  instanceCount
  instanceCount × {
    u32 templateId; u8 bucketId;
    i32 x, i32 y, i32 z          placement position, millimetres
    f32 rotY                     radians
    f32 scale                    uniform
    u8  modeFlags              0 = always | 1 = onlyIn turf | 2 = onlyIn zones
                               3 = notIn turf | 4 = notIn zones (variants.js L6;
                               the Rust runtime filters per mode ≡ main.js L235)
  }
  World transform ≡ props.js Builder.begin: compose(pos, rotY about +Y, scale³).
u32  spinCount
  spinCount × {
    u32 templateId; u8 bucketId;
    f32 m[12]                    WORLD base matrix, row-major 3×4
    f32 speed; f32 phase; u8 axis   0 = +Y, 1 = +Z (fan)
  }
  Animation ≡ props.js update L3271: M(t) = base × rot(axis, t·speed + phase).
  (Deviation from the extractor notes: matrices ride in WORLD space so records
  are self-contained; JS composes them onto the world matrix anyway.)
u32  blinkCount
  blinkCount × {
    i32 x, i32 y, i32 z          WORLD bulb position, millimetres
    f32 scale                    sphere radius (JS geometry = unit sphere)
    u8 r, g, b                   base colour
    f32 rate; f32 phase; f32 lo; f32 hi
  }
  Colour pulse ≡ props.js update L3280: s=0.5+0.5·sin(t·rate·2π+phase);
  k=s²(3−2s); on=k>0.6?1:k/0.6·0.25; colour = base × (lo+(hi−lo)·on).
u32  decorCount
  decorCount × {
    u32 templateId; u8 bucketId;
    i32 x, i32 y, i32 z          millimetres (0 for world-baked decor)
    f32 scale                    uniform (always 1)
  }
  Decor templates (spawn pads, lamps, palms, flag poles/cloth) are baked in
  WORLD space — their vertices already carry the final position; only the
  spawn-pad bases use the per-instance position (level.spawnPads).
```

Flags/banners from prop placements and the decor flag cloth are baked as
**static** geometry into the `paint` bucket (the cloth shader is not ported —
D-T53-6④). `blob` buckets are skipped entirely (shadow-catcher decals).
`glow` buckets keep their emissive multiplier folded into the u8 colour
(clamped). UVs are not extracted (the canvas atlas is not ported — D-T53-6②③).

## Manifest layout (`*.json`, stable key order)

```
meta        { stage, placements, templates, verts, tris, bin, binBytes,
              rawBytes, binSha256, buckets:[{name, ns}] }
placements  [{ i, type, pos, rotY, scale, modeFlags, instStart, instCount,
              tris, bbox:[min,max] }]        ≡ dressingFor(id) order incl. mirrors
lamps       [[x, y, z]…]                     final uLamps world positions
              ≡ levelMaterial.js setLevelLamps L28-36 (bulb x±0.92, y+4.9, ≤12)
murals      [{ id, rect:[u0,uw,v0,vh], place:[x0,xLen,y0,yLen], fx:[weather,chip] }]
              ≡ murals.js tex.userData.murals (atlas pixels NOT ported — D-T53-6③)
counts      { spin, blink, flags, banners, decorMeshes }
source      { commit }
```

## `special.json`

Same archive format with empty instance/spin/blink/decor tables; templates are
the named part geometries of `getSpecialProp(kind)` (special-props.js L454-463):

```
kinds  { <kind>: { parts: [{ name, bucket, tid, verts, tris }],
                   extras: { anchors (x,y,z arrays), dimensions, legsN:{at,side,index} } } }
```

Buckets by part role ≡ specials.js propMesh L202-208: body → `gloss` (plastic),
`*Ink` → `paint` (team-tinted by the runtime consumer), `glow` → `glow`.
